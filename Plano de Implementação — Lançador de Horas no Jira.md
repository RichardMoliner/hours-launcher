# Lançador de Horas no Jira — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a Manifest V3 Chrome extension that lets a user log Jira worklogs (time spent on a task) directly from the browser toolbar popup, without opening Jira.

**Architecture:** Pure-logic helpers (`lib/format.js`, `lib/jira-api.js`, `lib/storage.js`) are dependency-injected (fetch implementation, chrome.storage areas) so they can be unit-tested under plain Node with the built-in test runner — no bundler, no npm dependencies. `popup.js` is a thin orchestration layer that wires DOM events in `popup.html` to those helpers. There is no background service worker; all logic runs only while the popup is open.

**Tech Stack:** Vanilla JS (ES modules), HTML, CSS. Manifest V3. Node's built-in `node:test` + `node:assert/strict` for unit tests (Node 18.17+ required, no npm installs needed). No build step — the extension is loaded unpacked exactly as authored.

**Spec:** `Spec Extensão Chrome — Lançador de Horas no Jira.md` (repo root)

**Note on plan location:** saved at repo root (not `docs/superpowers/plans/`) to match this project's existing convention of keeping planning docs alongside the deliverable, established when the spec itself was kept at the root.

## Global Constraints

- Target instance: `https://desenv.betha.com.br` (Jira Server/Data Center, Basic Auth).
- Manifest V3, `permissions: ["storage"]`, `host_permissions: ["https://desenv.betha.com.br/*"]`.
- No background service worker — logic runs only while the popup is open.
- API base path: `/rest/api/2`.
- `started` worklog field format: `yyyy-MM-ddTHH:mm:ss.SSS±HHMM` (no colon in the offset).
- Local worklog history: capped at 5 entries, most recent first.
- Only the Basic Auth token (`base64(usuario:senha)`) is ever stored — never the raw password alone.
- Icon files (`icons/icon16.png`, `icon48.png`, `icon128.png`) are supplied by the user, not generated by this plan — manifest.json intentionally omits icon references until those files exist (see Task 14 follow-up).

export function buildStartedTimestamp(dateStr, timeStr, offsetMinutes) {
  const sign = offsetMinutes > 0 ? '-' : '+';
  const abs = Math.abs(offsetMinutes);
  const offsetHours = String(Math.floor(abs / 60)).padStart(2, '0');
  const offsetMins = String(abs % 60).padStart(2, '0');
  return `${dateStr}T${timeStr}:00.000${sign}${offsetHours}${offsetMins}`;
}
```

export function describeLoginError(status) {
  if (status === 401) return 'Usuário ou senha inválidos';
  return `Não foi possível fazer login (status ${status}).`;
}

export function describeApiError(status, { issueKey } = {}) {
  switch (status) {
    case 401:
      return 'Sessão expirada, faça login novamente';
    case 404:
      return issueKey
        ? `Tarefa ${issueKey} não encontrada. Confira a chave.`
        : 'Tarefa não encontrada. Confira a chave.';
    case 400:
      return 'Não foi possível interpretar o tempo informado. Use um formato como 2h, 1h 30m ou 45m.';
    default:
      return `Não foi possível completar a operação (status ${status}).`;
  }
}

import { addToHistoryEntry } from './format.js';

export function createAuthStore(sessionArea, localArea) {
  async function loadAuth() {
    const sessionResult = await sessionArea.get(['auth']);
    if (sessionResult.auth) return sessionResult.auth;
    const localResult = await localArea.get(['auth']);
    return localResult.auth ?? null;
  }

  async function saveAuth(auth, keepConnected) {
    await sessionArea.set({ auth });
    if (keepConnected) {
      await localArea.set({ auth });
    }
  }

  async function clearAuth() {
    await sessionArea.remove(['auth']);
    await localArea.remove(['auth']);
  }

  return { loadAuth, saveAuth, clearAuth };
}

export function createHistoryStore(localArea) {
  async function loadHistory() {
    const result = await localArea.get(['worklogHistory']);
    return result.worklogHistory ?? [];
  }

  async function addHistoryEntry(entry) {
    const current = await loadHistory();
    const next = addToHistoryEntry(current, entry, 5);
    await localArea.set({ worklogHistory: next });
    return next;
  }

  return { loadHistory, addHistoryEntry };
}
```
