Política de Privacidade

Extensão: Lançador de Horas no Jira · Última atualização: 21 de setembro de 2026

Esta extensão para o Google Chrome ("a extensão") foi desenvolvida para uso interno da Betha, permitindo que colaboradores lancem horas trabalhadas em tarefas do Jira sem precisar abrir o Jira no navegador. Esta política descreve quais dados a extensão acessa, como são usados e onde ficam armazenados.

Resumo

  • A extensão não envia dados para nenhum servidor de terceiros nem para qualquer servidor operado pelos desenvolvedores da extensão.
  • Toda comunicação acontece diretamente entre o seu navegador e a instância do Jira da Betha (https://desenv.betha.com.br).
  • Não há coleta de analytics, rastreamento de uso, nem compartilhamento de dados com terceiros.
  • Os dados ficam salvos apenas localmente, no seu navegador, e são removidos ao clicar em "Sair" ou ao desinstalar a extensão.

Quais dados a extensão acessa

DadoOrigemOnde fica armazenado
Usuário e senha do Jira Digitados por você na tela de login Não são salvos isoladamente. A senha é usada apenas em memória para montar o token de autenticação e nunca é gravada em disco separadamente.
Token de autenticação (Basic Auth, usuário:senha codificado em base64) Gerado a partir do usuário e senha informados chrome.storage.session (memória, some ao fechar o navegador) e, se a opção "Manter conectado" estiver marcada, também em chrome.storage.local (persiste entre reinícios do navegador).
Nome de exibição (displayName) e URL base do Jira Resposta da própria API do Jira após o login Mesmo local do token, para exibir a saudação e montar as chamadas seguintes.
Histórico dos últimos 5 lançamentos de horas (tarefa, tempo, data, descrição) Gerado pelos seus próprios lançamentos feitos pela extensão chrome.storage.local, apenas para conferência visual — o Jira continua sendo a fonte de verdade.
Chave, título e status de tarefas do Jira atribuídas a você Resposta da API do Jira ao consultar suas tarefas Exibidos temporariamente na tela da extensão; não são gravados em disco.

Como os dados são usados

Os dados acima são usados exclusivamente para autenticar você na sua própria instância do Jira e para permitir a consulta e o lançamento de horas trabalhadas nas tarefas às quais você tem acesso. Nenhum dado é usado para publicidade, perfis de comportamento, ou qualquer finalidade além do funcionamento da própria extensão.

Compartilhamento de dados

A extensão não compartilha, vende, transfere ou envia nenhum dado para terceiros. As únicas chamadas de rede feitas pela extensão são requisições diretas do seu navegador para a API REST do Jira em https://desenv.betha.com.br, usando a permissão de host declarada no manifesto da extensão (host_permissions), restrita a esse único domínio.

Permissões solicitadas

  • storage — necessária para salvar localmente o token de sessão e o histórico de lançamentos, para que você não precise fazer login toda vez que abrir a extensão.
  • host_permissions (desenv.betha.com.br) — necessária para que a extensão possa fazer chamadas diretas à API do Jira dessa instância específica.

Retenção e exclusão dos dados

Você controla a retenção dos seus dados a qualquer momento:

  • Clicar em "Sair" apaga imediatamente o token de autenticação salvo, tanto da sessão quanto do armazenamento persistente.
  • Desmarcar a opção "Manter conectado" faz com que o token seja removido automaticamente ao fechar o navegador.
  • Desinstalar a extensão remove todos os dados armazenados por ela (Chrome apaga automaticamente o chrome.storage de extensões desinstaladas).
  • O histórico local é limitado aos 5 lançamentos mais recentes; entradas mais antigas são descartadas automaticamente.

Observação de segurança: o token de autenticação é salvo apenas codificado em base64, não criptografado — qualquer pessoa com acesso ao seu perfil do Chrome conseguiria decodificá-lo. Por isso, recomendamos usar a extensão apenas em máquinas de trabalho de confiança, sob sua responsabilidade.

Alterações nesta política

Esta política pode ser atualizada caso a extensão passe a acessar outros dados ou serviços. A data da última atualização está indicada no topo desta página.
